Panduan Singkat Sistem KPI

  • Input Harian: Lakukan pengisian setiap hari kerja untuk setiap karyawan.
  • Skala Penilaian: Etos Kerja, Sikap & Kolaborasi, dan Dampak bernilai 1 - 10. Inovasi bernilai 1 - 4.
  • Pembulatan Otomatis: Nilai bulanan otomatis dihitung berdasarkan rata-rata harian dalam satu bulan penuh dan dibulatkan ke bilangan bulat terdekat.
  • Penyimpanan Aman: Data tersimpan otomatis di memori browser Anda (tidak hilang saat di-refresh). Gunakan tombol Backup JSON untuk mengamankan data ke file komputer.
